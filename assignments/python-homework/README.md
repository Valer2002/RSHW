## Ինչպես գործարկել

Պետք է տեղադրված լինի Python 3-ը։ Յուրաքանչյուր ֆայլ գործարկիր առանձին։
Այս պանակում բացիր տերմինալը և գրիր, օրինակ՝

```console
python task_01.py
```

Հաջորդ առաջադրանքի համար հրամանում փոխիր ֆայլի անունը։
Թվային դաշտերում մուտքագրիր թվեր, իսկ տասնորդականների դեպքում օգտագործիր կետ, օրինակ՝ `3.5`։
`task_08.py`-ում մուտքագրիր ամբողջ թիվ, իսկ `task_10.py`-ում՝ դրական ամբողջ թիվ։

Դաս 3-ի առաջադրանքներն այստեղ գրված են որպես սովորական ծրագրեր՝ առանց ֆունկցիա ստեղծելու։
